# 学术论文与开题报告写作技能 (Academic Writing)

本技能汲取自开源权威学术研究管道 [Imbad0202/academic-research-skills](https://github.com/Imbad0202/academic-research-skills)、同济大学机械工程与机器人学院标杆范式（郑祺耀优秀开题范式、杨佳轩全过程毕设经验）以及导师审阅红线，专门负责本课题学术文档正文的**构思、推导、起草、去 AI 腔与审校**。

---

## 一、 核心立项逻辑与学术红线（Iron Rules）

任何起草正文的动作，必须首先经过以下“四大铁律门禁”（违背即退回重写）：

1. **客观物理矛盾驱动立项（严禁大作业思维）**：
   - 课题的研究意义必须立足于**“微小型/紧凑水下航行器在特定恶劣物理场景（近壁面、受限水域、强非线性流扰）面临的共性物理矛盾与控制瓶颈”**；
   - 实验室已有样机（SwiftROV）仅作为后文方案验证的**物理实验载体**，**严禁在背景与意义中将“为实验室已有平台提供控制系统/基座”作为立项原因或核心研究意义**。
2. **构型定性准确（严禁再写开架式）**：
   - 实验室机器人为双圆柱耐压舱、碳纤维夹板紧凑集成的便携式水下航行器，**严禁出现“开架式 (Open-frame)”**表述。
3. **两阶段学术推导工作法（先定边界，再定细节）**：
   - 严格遵循**“文献证据先行 ➔ 对标优秀范文 ➔ 锁定章节契约元规则 ➔ 深入具体推演”**的四步递进工作法，严禁在未理清边界时盲目堆砌具体内容。
4. **旧版开题报告全量隔离**：
   - 严禁读取、恢复、全局搜索或沿用 2026/09/30 之前作废的旧版开题草稿与表述。

## 二、 去 AI 腔护栏与学术表达规范 (Style Calibration & AI-Tone Guardrails)

汲取自 `academic-paper` 的 Writing Quality Check 机制，正文起草严格消除以下 AI 典型通病：

### 1. 禁用浮夸与绝对化词汇（Inflated-Claim Wordlist）
- **中文禁用/慎用词**：`卓越`、`首次`、`唯一`、`完美解决`、`碾压`、`遥遥领先`、`颠覆性`、`极具开创性`、`深刻揭示`、`无与伦比`、`赋能`、`抓手`、`闭环生态`；
- **稳健替换策略**：
  - “完美解决了……难题” ➔ “有效抑制了……引起的状态波动” 或 “在一定程度上改善了……”；
  - “证明了该算法的卓越性能” ➔ “仿真与实验表明，该方法在阶跃与扰动工况下具有较小的跟踪误差”；
  - “首次提出” ➔ “结合本平台八推进器构型特点，构建了……”。

### 2. 消除机械句式与排版噪音
- **禁用破折号（`——` / `—`）连接分句**：AI 极度喜欢用破折号插入解释或制造总结感。学术论文一律改用逗号、分号、括号或独立从句；
- **禁止机械排比与假三段论**：避免每段开头都用“首先……其次……最后……”；避免滥用“不仅……而且……”；
- **禁止同义词轮换（Synonym Cycling）**：同一物理量或概念全文保持唯一规范术语（如统一使用“附体坐标系”，不要交替使用“载体系”、“船体系”、“机体系”）；
- **杜绝碎片化小标题与机械加粗**：正文应以连贯扎实的学术散文（Prose）呈现，严禁写成满篇带加粗前缀的 Bullet Points 列表。

## 三、 开题报告正文撰写模式与段落契约 (Section Contracts)

正文起草必须严格对标学校官方模板与郑祺耀标杆范式，按章节契约推进：

### 1. §1.1 课题来源及研究的目的和意义（标准三段式，约 800~1000 字）
- **第 1 段（宏观战略高位与装备需求）**：国家十四五规划 / 十七部门《“机器人+”》通知 ➔ 水下基础设施无人化替代 ➔ 紧凑型 ROV 不可替代性；
- **第 2 段（客观物理环境矛盾与 8 推构型控制瓶颈）**：水下高密度黏性介质强流扰、水动力附加质量与非线性阻尼耗散 ➔ 4/6 推欠驱动抗扰缺陷 ➔ 8 推空间过驱动优势 ➔ 引出“推力饱和导致合成力矩严重畸变（翻滚失控）”行业通病；
- **第 3 段（课题针对性解决思路与预期价值）**：引入 PX4 高频实时架构 ➔ 机理参数辨识 + 模型前馈解耦补偿 + 力矩优先抗饱和分配闭环 ➔ 水下稳定作业工程价值（样机仅作验证载体）。

### 2. §1.2 国内外研究现状与发展趋势（文献综述，约 2000~2500 字）
梳理四大主干板块，以权威综述（Makam 2023、Yuh 2000、Johansen 2013、Capocci 2017）为纲，各技术分支与后文“研究内容”严格 1:1 镜像对应：
1. **水下航行器六自由度机理建模与参数辨识研究现状**：经验公式法 ➔ CFD数值法 ➔ 水池试验法（大型PMM vs Caccia板载传感器辨识工程金标准） ➔ 时域数据驱动辨识（Park动量回归、Harris零空间辨识、PINN/SINDy）；
2. **水下航行器鲁棒运动控制与动态补偿研究现状**：经典线性解耦流派 ➔ 基于模型的非线性变换（Smallwood实机消融验证范式） ➔ 李雅普诺夫反步法 ➔ 滑模控制流派（Yoerger、Healey解耦） ➔ 主动抗扰与增量控制（ADRC/INDI） ➔ 预测优化流派（NMPC、Neural-Fly）；
3. **过驱动多推进器控制分配与推力饱和处理研究现状**：显式解析法（伪逆） ➔ 启发式抗饱和分配（直接截断畸变危害 vs 保方向等比例缩放/力矩优先分配 vs 序贯解饱和） ➔ 约束优化分配（QP）；
4. **发展趋势与现有局限评判**：总结前人局限，顺理成章引出本课题切入点。

### 3. §2.1 主要研究内容（干什么）
收敛至三大理论主干：
1. 六自由度动力学机理建模与低成本水动力参数辨识；
2. 基于动力学逆解耦前馈补偿与状态反馈的运动控制律构建；
3. 过驱动八推进器推力分配与饱和状态下的力矩优先控制。

### 4. §2.2 研究方案（怎么干与为什么能做成）
- **拟采取的研究方法**：纯技术实施工具（机理推导、飞控二次开发、对比消融评估）；
- **技术路线图**：五步递进实施流程；
- **三重可行性分析**：理论可行性、软件仿真可行性、硬件实验条件可行性。

## 四、 证据门控与审稿人自检清单 (Pre-Submission Review)

每完成一个小节正文起草，必须按以下 5 项门禁自查自纠：

1. **证据门控（Evidence Discipline）**：
   - 事实性陈述与指标是否严格遵守 L1（实测/全文）~ L3（元数据）等级？
   - 严禁编造推进器硬件型号、水池尺寸；草稿中未测数值统一用 `--`，绝不编造具体百分比指标。
2. **逻辑咬合度（Logic Closure）**：
   - §1.1 背景中提出的痛点（水动力强耦合、推力饱和力矩畸变），在 §2.1 研究内容与 §2.2 方案中是否 100% 具备对应的解法？
3. **符号与术语一致性**：
   - 全文公式符号、上标、下标是否遵循通用动力学标准？首次出现的物理量是否均有明确定义？
4. **文献引用真实性**：
   - 正文引用的所有 `[1]~[N]` 是否均来自真实的已入库文献？首次出现顺序是否严格单调递增？
5. **去 AI 腔验收**：
   - 是否排除了所有破折号连接句？是否存在空洞的公文式排比句？
