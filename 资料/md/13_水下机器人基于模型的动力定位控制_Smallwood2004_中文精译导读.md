> **英文原题**：Model-Based Dynamic Positioning of Underwater Robotic Vehicles: Theory and Experiment  
> **论文作者**：David A. Smallwood, Louis L. Whitcomb (IEEE Fellow, 约翰霍普金斯大学 JHU 教授)  
> **所属机构**：约翰霍普金斯大学机械工程系动力系统与控制实验室（DSCL, Johns Hopkins University）  
> **出版出处**：*IEEE Journal of Oceanic Engineering*, 29(1): 169–186, January 2004  
> **学术地位**：水下机器人控制领域被誉为“实物对比验证金标准”的里程碑论文（被引 500+ 次），首次在全实物水池环境下对经典独立回路 PD、非线性解耦动态逆（ND-PD）、基于模型的动力学前馈补偿（MB-PD）及自适应控制进行了高精度消融对比实验。

## 一、 论文核心动机：基于模型的控制到底能在物理实机上带来多少提升？

在水下控制理论界，学者们提出了大量复杂的非线性控制理论（如微分几何反馈线性化、李雅普诺夫反步法、高阶滑模等），但在工业水下工程界，绝大多数商用 ROV 依然顽固地沿用最简陋的单轴独立 PID 控制。

工程界对先进模型控制持怀疑态度的主要症结在于：
1. **水下参数测量成本高昂且充满误差**；
2. **缺乏严格可重复的物理对比实验**：学术界多数论文仅展示仿真曲线，回避了真实传感器噪声、推力死区与水动力迟滞等物理非理想因素。

Smallwood 和 Whitcomb 团队在 JHU 实验水池中，利用自主研制的具备全自由度推进能力的 JHU ROV，配备水下光学精确定位系统与多普勒测速仪（DVL），**设计了长达数百小时的严苛受控轨迹跟踪实验，用无可辩驳的物理数据回答了“模型动力学补偿到底有无实际工程价值”**。

## 二、 六大受测控制器统一对比矩阵

论文在完全相同的物理实体、相同的水池流场与相同的参考轨迹下，对以下控制方案进行了严格横向消融测试：

```
                    Smallwood & Whitcomb 控制器消融对比阵列
┌───────────────────────┬─────────────────────────────┬─────────────────────────────────┐
│ 控制器类型            │ 数学控制律结构              │ 对水动力模型信息的依赖程度      │
├───────────────────────┼─────────────────────────────┼─────────────────────────────────┤
│ 1. 独立解耦 PD        │ τ = Kp e + Kd ė             │ 完全无模型 (Model-Free)         │
│ 2. 非线性解耦 (ND-PD) │ τ = D(v)v + g(η) + Kp e...  │ 依赖阻尼 D 与重浮力 g 模型      │
│ 3. 基于模型前馈(MB-PD)│ τ = M vd_dot + D(v)v + g... │ 依赖完整全惯性 M、阻尼 D、恢复力│
│ 4. 滑模变结构 (SMC)   │ τ = f_hat - K sat(s/Φ)      │ 依赖标称模型 + 不确定性上界     │
│ 5. 在线自适应控制     │ τ = Y(q,v,a) θ_hat + Kd s   │ 无需先验参数，需持续激励在线回归│
└───────────────────────┴─────────────────────────────┴─────────────────────────────────┘
```

### 2.1 基于模型前馈补偿（Model-Based Feedforward, MB-PD）的经典形式：
$$
\boldsymbol{\tau} = \hat{\boldsymbol{M}} \dot{\boldsymbol{\nu}}_d + \hat{\boldsymbol{C}}(\boldsymbol{\nu})\boldsymbol{\nu}_d + \hat{\boldsymbol{D}}(\boldsymbol{\nu})\boldsymbol{\nu}_d + \hat{\boldsymbol{g}}(\boldsymbol{\eta}) + \boldsymbol{K}_p \tilde{\boldsymbol{\eta}} + \boldsymbol{K}_d \tilde{\boldsymbol{\nu}}
$$
- 前半部分为**标称动力学前馈项（Feedforward Inversion）**：利用期望轨迹加速度 $\dot{\boldsymbol{\nu}}_d$ 与速度 $\boldsymbol{\nu}_d$ 计算出理想标称推力，提前注入系统，消除了绝大部分已知的惯性、阻尼阻力与静态重浮力偏置；
- 后半部分为**误差反馈项（PD Feedback）**：仅需微调并克服未建模残差扰动与突发水流冲击。

## 三、 震撼业界的定量实物实验结论

论文的海量物理水池对比数据得出了几个颠覆传统工程直觉的定论：

1. **跟踪精度提升高达 2~3 倍**：
   在相同的位置闭环反馈增益下，引入**模型动力学前馈补偿（MB-PD）相较于无模型的纯 PD 控制，三维轨迹均方根误差（RMS Error）降低了 50%~70%**！
2. **能耗与推力剧烈程度显著下降**：
   纯 PD 控制为了克服未知阻力，必须被迫调高比例增益 $K_p$，导致推进器在高频噪声下疯狂振荡、电机发热；而基于模型前馈的控制器将绝大部分驱动负荷转移到了平滑的解析前馈项上，推进器输出极其平顺，控制能耗降低了约 25%；
3. **鲁棒性余量惊人**：
   实验故意在模型参数中人为引入 $\pm 30\%$ 的附加质量与阻尼偏差，MB-PD 控制器依然保持了远优于纯 PD 的控制品质，**直接粉碎了“模型参数若不 100% 精确，基于模型的控制就毫无意义”的行业偏见**！

## 四、 对本课题方案论证的决定性支撑（立项定心丸）

Smallwood & Whitcomb (2004) 是我们本科毕业论文最核心的“立项与方案定心丸”：
1. **直接为本课题的技术路线奠定合法性**：本课题题目为《基于PX4的水下航行器模型控制方法研究》，Smallwood (2004) 在顶刊上用实物证明了“标称模型补偿 + 状态反馈”是兼顾精度、平稳性与算力开销的最佳物理闭环；
2. **明确了本科毕设的对比验证标准**：论文不必狂妄地宣称“发明了超越工业界的全新数学理论”，而是严谨对标 Smallwood 范式——**在仿真与物理平台上，构建“无模型基准（纯 PID） vs 动力学解耦补偿控制”的严格消融对比，用实验数据证明模型补偿带来的抗扰增益**！
