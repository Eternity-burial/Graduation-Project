## 一、 论文核心贡献与解耦控制哲学

在全自主水下航行器（如文中的 NPS AUV II 样机）执行复杂空间机动任务时，平动（Surge, Sway, Heave）与转动（Roll, Pitch, Yaw）之间存在极其剧烈的非线性交叉耦合动力学：
- 快速打舵转向时，科氏力与离心力会导致航行器伴生严重的横滚倾侧（Roll Induced by Yaw）与纵倾下潜；
- 垂向升降舵产生俯仰力矩的同时，会诱发附体阻力激增与航速跌落。

若直接针对未解耦的 6-DOF 强耦合非线性方程设计全状态控制器，其李雅普诺夫函数构造极其复杂且在线调参维度过高。Healey 和 Lienard 提出了享誉控制界的**多变量功能子系统解耦与交叉耦合滑模鲁棒抵消思想**：

```
                    Healey & Lienard 三大功能子系统解耦框架
                      ┌─────────────────────────────────┐
                      │ 全状态 6-DOF 非线性流体动力学系统 │
                      └────────────────┬────────────────┘
                                       │ 物理弱耦合分解
        ┌──────────────────────────────┼──────────────────────────────┐
        ▼                              ▼                              ▼
┌───────────────────────┐      ┌───────────────────────┐      ┌───────────────────────┐
│  航速子系统 (Speed)   │      │ 转向子系统 (Steering) │      │  潜浮子系统 (Diving)  │
│ 纵荡 u 与主机转速 n   │      │ 横荡 v, 横摇 p, 艏向 r│      │ 垂荡 w, 纵摇 q, 深度 z│
│ 控制器: 纵向滑模调速律 │      │ 控制器: 横摆滑模自动舵│      │ 控制器: 深度-俯仰滑模 │
└───────────────────────┘      └───────────────────────┘      └───────────────────────┘
```

各子系统之间的残留动态与非线性耦合项不作为主要控制回路进行复杂配平，而是**统一归入各通道的有界未建模扰动向量中，由滑模控制器的强鲁棒滑动模态给予完全抑制**。

## 二、 多变量滑模自动舵的数学推导

以**转向子系统（Steering Subsystem）**为例，状态向量选取为横荡速度 $v$、横滚角速度 $p$、横滚角 $\phi$ 与偏航角速度 $r$：
$$
\dot{\boldsymbol{x}}(t) = \boldsymbol{A} \boldsymbol{x}(t) + \boldsymbol{b} \delta_r(t) + \boldsymbol{f}(\boldsymbol{x}, \boldsymbol{d})
$$
其中 $\delta_r$ 为方向舵偏角（或推进器差动偏航指令），$\boldsymbol{f}(\boldsymbol{x}, \boldsymbol{d})$ 包含来自潜浮通道的交叉力矩和水流扰动。

### 2.1 多变量切换面构造
定义偏航角跟踪误差 $\tilde{\psi} = \psi - \psi_d$，构造包含横滚阻尼与偏航误差的状态线性组合滑模面：
$$
\sigma(t) = \boldsymbol{s}^T \tilde{\boldsymbol{x}}(t) = s_1 v + s_2 p + s_3 \phi + s_4 (r - r_d) + s_5 \tilde{\psi}
$$
其中权重向量 $\boldsymbol{s}$ 通过特征值极点配置（Pole Placement）或 LQR 优化确定，确保滑动模态 $\sigma(t) = 0$ 时系统的零动态具有满意的阻尼比与快速收敛性。

### 2.2 控制律综合与双曲正切平滑
通过计算使得 $\dot{\sigma}(t) = -\eta \tanh(\sigma / \phi_0)$，解出方向舵控制律：
$$
\delta_r(t) = -(\boldsymbol{s}^T \boldsymbol{b})^{-1} \left[ \boldsymbol{s}^T \boldsymbol{A} \boldsymbol{x} + \boldsymbol{s}^T \hat{\boldsymbol{f}} + \eta \tanh\left(\frac{\sigma(t)}{\phi_0}\right) \right]
$$
双曲正切函数 $\tanh(\cdot)$ 连续平滑无毛刺，完全消除了物理舵机与推进器的机械高频振荡。

## 三、 对本课题运动控制架构的权威指导

Healey & Lienard (1993) 为我们开题报告构建的运动控制方案提供了不可替代的理论支撑：
1. **子系统解耦的正当性**：文献在数学与实验上充分论证了，在中小航速与水平机动工况下，按自由度功能进行子系统解耦是完全可行且极其高效的工程标准；
2. **PX4 飞控层级控制的契合性**：PX4 飞控原生采用了类似的角速度内环与位置/角度外环分离架构，Healey 的解耦滑模理论为我们在 PX4 固件中引入模型前馈补偿提供了最强有力的顶刊背书。
