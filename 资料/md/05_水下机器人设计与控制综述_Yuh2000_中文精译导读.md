> **论文作者**：J. Yuh (IEEE Fellow)

## 一、 论文核心背景与全景脉络

在 1990 年代，随着海洋资源勘探与深海科学考察的迫切需求，自主水下机器人（AUV/ROV）研发迎来了爆发式增长。然而，水下高密度黏性介质带来的复杂非线性水动力学效应（附加质量、非线性水动力阻尼、强流场扰动以及高度运动耦合），使得传统的陆地轮式机器人与空间飞行器控制理论难以直接迁移。

Yuh 教授立足于夏威夷大学两代实验样机（Omni-Directional Intelligent Navigator, ODIN）等工程实践，系统总结并建立了**水下机器人六自由度非线性动力学建模与运动控制算法的六大流派谱系**：

```
水下机器人运动控制理论谱系（Yuh 2000 综述划分）
├── 1. 线性控制流派 (Linear Control Methods)
│      ├── 经典 PID / 增益调度 PID (Gain Scheduling PID)
│      └── 状态空间线性二次型调节器 (LQR / LQG)
├── 2. 基于模型的非线性变换流派 (Model-Based Decoupling & Inversion)
│      ├── 反馈线性化 (Feedback Linearization)
│      └── 计算力矩法 / 动态逆控制 (Computed Torque / Dynamic Inversion)
├── 3. 强鲁棒非线性流派 (Robust Nonlinear Control)
│      ├── 滑模变结构控制 (Sliding Mode Control, SMC - Yoerger 1985, Healey 1993)
│      └── H-infinity 鲁棒 $H_\infty$ 控制
├── 4. 自适应控制流派 (Adaptive Control Methods)
│      ├── 模型参考自适应控制 (MRAC)
│      └── 自校正自适应滑模控制 (Self-tuning Adaptive SMC, Yuh 1990)
├── 5. 智能与学习控制流派 (Learning & Intelligent Control)
│      ├── 神经元网络动态补偿 (Neural Network Control)
│      └── 模糊逻辑控制 (Fuzzy Logic Control)
└── 6. 多航行器协同与混合控制 (Hybrid & Cooperative Systems)
```

## 二、 水下航行器六自由度标准动力学模型

论文首先给出了学术界公认的水下航行器六自由度非线性矩阵微分方程（与 Fossen 体系完全一致）：

$$
\boldsymbol{M} \dot{\boldsymbol{\nu}} + \boldsymbol{C}(\boldsymbol{\nu})\boldsymbol{\nu} + \boldsymbol{D}(\boldsymbol{\nu})\boldsymbol{\nu} + \boldsymbol{g}(\boldsymbol{\eta}) = \boldsymbol{\tau}
$$

$$
\dot{\boldsymbol{\eta}} = \boldsymbol{J}(\boldsymbol{\eta}) \boldsymbol{\nu}
$$

其中：
- $\boldsymbol{\eta} = [x, y, z, \phi, \theta, \psi]^T$ 为地球固定惯性系下的位姿向量；
- $\boldsymbol{\nu} = [u, v, w, p, q, r]^T$ 为航行器体固坐标系下的线速度与角速度向量；
- $\boldsymbol{M} = \boldsymbol{M}_{RB} + \boldsymbol{M}_A$ 为刚体惯性与流体附加质量总和，满足对称正定性；
- $\boldsymbol{C}(\boldsymbol{\nu}) = \boldsymbol{C}_{RB}(\boldsymbol{\nu}) + \boldsymbol{C}_A(\boldsymbol{\nu})$ 为刚体与流体附加科氏向心力矩阵；
- $\boldsymbol{D}(\boldsymbol{\nu}) = \boldsymbol{D}_L + \boldsymbol{D}_{NL}(\boldsymbol{\nu})$ 为线性黏性阻尼与二次压差阻尼项；
- $\boldsymbol{g}(\boldsymbol{\eta})$ 为重力与浮力合成的被动静水恢复力向量；
- $\boldsymbol{\tau}$ 为多推进器在航行器质心处合成的广义控制力与力矩向量。

## 三、 各大运动控制流派深入剖析与优缺点对比

### 3.1 线性控制流派 (PID / LQR)
- **核心思想**：忽略跨轴交叉耦合项，在某一标称工作点（如平直低速巡航状态）将六自由度动力学泰勒展开线性化，构建独立的单输入单输出（SISO）PID 控制回路。
- **优点**：计算开销极低，参数调试直观，工程可靠性经过数十年工业验证。
- **局限性**：水下机器人动力学在全包线内高度非线性，一旦离开线性化设定点或遭遇突发水流冲击，固定增益 PID 会出现严重的超调甚至失稳振荡。

### 3.2 基于模型的非线性逆控制 (Dynamic Inversion / NDI)
- **核心思想**：若航行器的水动力参数（$\boldsymbol{M}, \boldsymbol{C}, \boldsymbol{D}, \boldsymbol{g}$）已知，可通过前馈计算抵消非线性项：
  $$
  \boldsymbol{\tau} = \hat{\boldsymbol{M}} \boldsymbol{\alpha} + \hat{\boldsymbol{C}}(\boldsymbol{\nu})\boldsymbol{\nu} + \hat{\boldsymbol{D}}(\boldsymbol{\nu})\boldsymbol{\nu} + \hat{\boldsymbol{g}}(\boldsymbol{\eta})
  $$
  其中 $\boldsymbol{\alpha} = \dot{\boldsymbol{\nu}}_d + \boldsymbol{K}_d \dot{\boldsymbol{e}} + \boldsymbol{K}_p \boldsymbol{e}$ 为期望虚拟加速度输入。代入真实系统后，非线性动态被完全抵消，闭环误差方程退化为线性解耦的指数渐近稳定二阶系统。
- **优点**：能够在大范围机动时保持全局一致的动态响应速度。
- **局限性**：对离线标定模型的精确度要求极高，若水动力导数辨识不准或遭遇未知流扰，动态逆不仅无法完全对消扰动，反而可能引入负面模型误差。

### 3.3 滑模变结构控制 (Sliding Mode Control, SMC)
- **核心思想**：定义滑动模态切换面 $s = \dot{e} + \lambda e$，利用高频符号切换项（如 $\eta \operatorname{sgn}(s)$）强迫系统状态轨迹在有限时间内收敛至滑模面并在面上滑动。
- **优点**：对模型参数摄动和外界匹配扰动具有天然的完全不变性（Complete Invariance），无需精确辨识阻尼参数。
- **局限性**：符号函数高频切换会导致物理推进器的剧烈抖振（Chattering），引起电机过热与机械磨损，工程上必须引入饱和边界层连续化函数（Boundary Layer Saturation）进行平滑。

### 3.4 自适应与学习控制 (Adaptive & Neural Control)
- **核心思想**：针对未知的质量变化与流体阻尼系数，构建在线参数自适应律（如基于线性回归子的梯度下降或李雅普诺夫自校正）或利用神经网络逼近未知非线性残差。
- **优点**：无需先验精确建模，能够适应有效载荷增减与不同流场工况。
- **局限性**：自适应律需要满足严格的持续激励条件（Persistence of Excitation, PE），否则参数估计可能漂移发散；神经网络在线计算开销较大，嵌入式部署受限。

## 四、 对本课题控制方案设计的权威启示

Yuh 综述为本毕业论文的技术路线选择提供了最坚实的学术论据：
1. **纯 PID 的不适用性**：八推进器紧凑型 ROV 在多维水流冲击下存在剧烈的非线性阻尼与跨轴耦合，直接证明了脱离动力学模型的单回路 PID 无法满足高精度抗扰要求；
2. **标称模型前馈补偿 + 闭环反馈架构的合理性**：既规避了纯动态逆对精确模型的过度依赖，又借助 PX4 高频底层角速度内环抑制了残差扰动，兼顾了控制带宽与工程鲁棒性；
3. **推力分配的重要性**：Yuh 综述明确指出，对于过驱动（Over-actuated）水下机器人，控制律生成的广义力矩必须通过可靠的控制分配矩阵映射至各物理推进器，执行机构饱和是引发闭环失稳的关键诱因。
