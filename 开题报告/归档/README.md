# 开题与任务书阶段归档资料说明 (`开题报告/归档/`)

本目录用于存放课题开题与任务书阶段的**历史 DOC 兼容版本、前期草案、用户手工标注备份以及历次旧版修改对比文档**。

根据项目**“DOCX 优先”**工作规范：
- 主工作区（`开题报告/` 根目录）**仅保留当前最新的规范 `.docx` 交付件及当前活跃轮次的修改对比版**；
- 所有历史 `.doc` 文件以及后续迭代中产生的**旧版修改对比文件**全部移入本归档目录妥善保存，确保工作区整洁且版本演进脉络 100% 清晰可查。
