
# Project Facts

## 文件定位

本文件管理当前有效的项目事实，不承担历史进度记录、学术写作指导或研究路线规划的职责。

项目事实只能在有依据的情况下确认或修改。

## 事实状态

- CONFIRMED：已由项目负责人确认，或由可核实的原始证据支持。
- PROVISIONAL：暂定认识，尚不能作为确定事实。
- SUPERSEDED：已被新事实替代，仅供变更追溯。
- DISPUTED：存在冲突，需要进一步确认。

项目正文只能将适用范围内的 CONFIRMED 条目直接写成事实。

对原始证据尚不充分的用户确认事项，必须保留相应的证据状态，不能伪称已完成独立核验。

## 事实变更协议

修改已有事实时：

1. 给出新依据。
2. 确定受影响的对象与适用范围。
3. 明确旧描述为何失效。
4. 更新事实状态。
5. 检查受影响的正式正文。
6. 在版本记录中保留修改原因。

不得仅因 AI 生成了新的解释，就改变 CONFIRMED 事实。

研究算法选择、工作进度和个人写作偏好不得写入本文件。
