
# Project Facts

## 文件定位

本文件管理当前有效的项目事实，不承担历史进度记录、学术写作指导或研究路线规划的职责。

项目事实只能在有依据的情况下确认或修改。

## 事实状态

- CONFIRMED：已由项目负责人确认，或由可核实的原始证据支持。
- PROVISIONAL：暂定认识，尚不能作为确定事实。
- SUPERSEDED：已被新事实替代，仅供变更追溯。
- DISPUTED：存在冲突，需要进一步确认。

项目正文只能将适用范围内的 CONFIRMED 条目直接写成事实。

对原始证据尚不充分的用户确认事项，必须保留相应的证据状态，不能伪称已完成独立核验。

## 当前事实

### F-001：实验平台物理构型与控制学科特征抽象

状态：CONFIRMED（项目负责人确认）

当前有效描述：

研究平台为八推进器紧凑型水下航行器（SwiftROV / Compact Vectored ROV），采用紧凑集成构型。

控制学科关注的核心特征（研究重点）：

1. 执行机构构型：空间对称与矢量倾斜布置的 8 推进器空间过驱动冗余系统，具备全自由度主动调姿能力，同时存在推力分配与饱和耦合非线性；
2. 水动力与动力学特性：空间对称紧凑钝体低速水动力特性，呈现显著的二次非线性流阻、高附加质量效应与重浮力偏置被动恢复稳性矩 g(η)；
3. 尺度与边缘算力约束：微小型便携式尺度，动态响应频带宽，受限于机载嵌入式计算资源（构成高精度预测模型与在线求解耗时的核心矛盾）。

非控制重点与降级处理：

1. 双舱集成仅作为物理实验样机硬件外观的一句中性几何背景交代，绝非控制算法的理论创新或主语；
2. 机械加工材料（碳纤维、亚克力、铝合金等）、结构尺寸与耐压舱装配细节不属于控制学科研究范围，严禁作为论文重点论述。

适用范围：

描述本项目使用的物理实验平台时，应采用上述控制特征与构型描述。不得将其他水下机器人的常见结构直接移植到本平台。

依据：

项目负责人纠正记录、导师审阅意见及当前 AGENTS.md。

历史失效描述：

1. 将本项目平台直接称为“开架式”属于已明确纠正的定性错误；
2. 将耐压舱机械结构、材料或零件清单作为控制课题重点论述属于严重的大作业思维偏离。

## 事实变更协议

修改已有事实时：

1. 给出新依据。
2. 确定受影响的对象与适用范围。
3. 明确旧描述为何失效。
4. 更新事实状态。
5. 检查受影响的正式正文。
6. 在版本记录中保留修改原因。
