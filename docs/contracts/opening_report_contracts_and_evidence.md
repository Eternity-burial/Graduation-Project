# 开题报告章节契约、证据映射与学术规范指南 (Opening Report Contracts & Evidence)

> [!IMPORTANT]
> **【当前内容状态声明 (Document Status & Scope of Authority)】**
> 1. **框架参考性**：本文档定义的章节功能、结构边界与组织框架供后续撰写参考；
> 2. **路线未决性**：技术路线与研究任务细分尚未最终确认，目前处于审视与动态论证中；
> 3. **证据门控性**：未经充分原始证据核实的技术判断不能作为 CONFIRMED 事实；
> 4. **防自动升级**：不得将本文档中历史遗留的技术假设或具体算法推演自动升级为当前既定研究决定。

> **核心哲学（借鉴顶级开源学术写作体系 `researchwrite`）**：
> 1. **证据先于文字（Evidence before prose）**：起草前必须核实物理事实与文献证据，无证据不写断言；
> 2. **论证先于章节（Argument before sections）**：写正文前必须理顺物理矛盾到技术路径的因果映射；
> 3. **契约先于段落（Contracts before paragraphs）**：每一节必须先明确使命、上游输入、准入主张、禁用红线与验收标准；
> 4. **范围先于完备（Scope before completeness）**：分阶段推进，先锁定性质边界，再讨论具体细节；
> 5. **未决事项显式挂起（Unresolved Claims）**：未达成共识的事项显式列为未决，绝不擅自硬编码为既定事实。

### 【契约 1.1-P1】第一节·段落 1：宏观战略与人工作业替代
* **[Purpose]**：从国家政策导向与水下无人化作业的战略必要性出发，确立立项宏观高度。
* **[Inputs]**：工信部等十七部门《“机器人+”应用行动实施方案》（工信部联通装〔2022〕187号）、国家海洋强国战略文件。
* **[Allowed Claims]**：
  1. 海洋战略与水下高价值基础设施（风电桩基、海底管网、水下结构物）的重要地位；
  2. 传统潜水员水下作业的高危致命风险（高压、暗涌、低温、减压病）；
  3. 传统重型工作级 ROV（数吨重）无法进入狭窄受限空间且动员成本高昂；
  4. 发展便携紧凑型水下航行器实现高危作业无人化替代的必然性。
* **[Forbidden Claims]**：FC-01, FC-02, FC-03, FC-04。
* **[Validation Criteria]**：是否自然论证了“人干不了、大装备进不去，所以必须研发便携式水下航行器”？

### 【契约 1.1-P2】第一节·段落 2：作业环境物理矛盾与 8 推过驱动演进通病
* **[Purpose]**：从作业场景出发，揭示水动力学与扰动难点，论证构型升级到 8 推的必然性，并引出行业共性控制通病。
* **[Inputs]**：FACT-01 ~ FACT-03（流体物理事实）；FACT-05 ~ FACT-09（构型对比与通病事实）；导师 9/30 录音指示。
* **[Allowed Claims]**：
  1. 近结构物复杂流场下的强非线性阻尼与变流/湍流扰动，极易诱发姿态失稳与多轴耦合偏航；
  2. 构型对比：3~4推缺失横荡（Sway欠驱动），6推横滚与俯仰完全依赖被动重浮力自稳（无法主动俯仰调姿）；
  3. 8推空间矢量过驱动的必然性：实现真正空间 6-DOF 全解耦独立可控，赋能全姿态倾斜悬停与主动抗倾覆能力；
  4. 引出行业通病：复杂流扰下推进器受流不对称平衡难点；推力饱和直接硬截断导致合成力矩严重畸变（Torque Distortion），反向诱发剧烈翻滚失控。
* **[Forbidden Claims]**：FC-01, FC-02, FC-03, FC-04。
* **[Validation Criteria]**：是否清晰建立“为了全姿态机动必须用 8 推，但 8 推又引入了受流不均与推力饱和力矩畸变行业通病”的递进逻辑？
